03. SQL & PostgreSQL

Analyse de Satisfaction Client

SQL PostgreSQL NPS (Net Promoter Score) Requêtes CTEs Recommandations Métier
Problématique

Comprendre les causes profondes de l'insatisfaction client à partir d'une volumétrie importante de retours, notes et historiques de commandes.

Traitement / Analyse

Extraction et agrégation sous PostgreSQL avec des requêtes SQL avancées (CTEs, fonctions de fenêtrage, calculs statistiques) pour catégoriser les retours.

Solution

Segmentation des répondants (Promoteurs, Passifs, Détracteurs), croisement avec les délais de livraison et cartographie des motifs d'insatisfaction.

Résultat

Identification des étapes critiques de rupture de service et production de recommandations actionnables pour orienter les décisions d'amélioration de l'expérience client.

PostgreSQL — Calcul dynamique du Net Promoter Score
WITH nps_calc AS (
  SELECT COUNT(*) AS total, COUNT(*) FILTER (WHERE score >= 9) AS promoteurs, COUNT(*) FILTER (WHERE score <= 6) AS detracteurs FROM avis_clients
) SELECT ROUND((promoteurs::numeric / total - detracteurs::numeric / total) * 100, 2) AS nps_score FROM nps_calc;
