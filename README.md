## 🌐 Déploiement Gratuit sur GitHub Pages (2 minutes)

1. Créez un dépôt sur votre compte GitHub nommé par exemple `portfolio`.
2. Poussez l'ensemble des fichiers (`index.html`, `css/`, `js/`, `img/`, `README.md`).
3. Dans votre dépôt GitHub, accédez à **Settings** > **Pages**.
4. Sous **Branch**, sélectionnez `main` (ou `master`) et le dossier `/ (root)`, puis cliquez sur **Save**.
5. Votre portfolio sera accessible en ligne à l'adresse : `https://bassecou.github.io/portfolio/` !
